# Bitcount Single Font

This directory should contain the Bitcount Single font files.

## Required Files

Place the following `.ttf` or `.otf` files in this directory:

- `BitcountSingleCircle-Regular.otf` - Regular weight
- `BitcountSingleCircle-Bold.otf` - Bold weight (optional)

## Font Source

Bitcount Single is designed by Petr van Blokland / TYPETR.
Available at: https://www.typetr.com/fonts/bitcount

## After Adding Fonts

The app is already configured to load these fonts. Once you add the files:

1. Restart the Expo development server
2. The fonts will be automatically loaded on app start
